# Weihnachtsmarkt-Standplan

Eine browserbasierte Planungs-App für den Weihnachtsmarkt der Wilhelm-Bracke-Gesamtschule. Die Anwendung benötigt keinen Server und verarbeitet hochgeladene CSV-Dateien lokal im Browser.

## Website

Die GitHub-Pages-Website wird aus `Standplan.html` bereitgestellt. Der Pages-Workflow veröffentlicht diese Datei als `index.html` und kopiert die benötigten Bilder und die Standplanung-CSV in das Website-Verzeichnis.

## Lokal starten

`Standplan.html` im Browser öffnen. Die mitgelieferte Datei `weihnachtsmarkt_standplanung.csv` kann in der App importiert werden. Alternativ die CSV-Datei in das Upload-Feld ziehen.

## Dateien

- `Standplan.html` – eigenständige Web-App
- `schule.png` – Luftbild für den Lageplan
- `schule_maske.png` – Flächenmaske
- `weihnachtsmarkt_standplanung.csv` – Beispieldaten für die Standplanung

**Datenschutzhinweis:** Dieses Repository und seine GitHub-Pages-Website sind öffentlich. Die Beispieldaten-CSV wird mitveröffentlicht und kann von allen Website-Besuchern heruntergeladen werden.
